# 广科教务课表爬虫

把教务系统的课表抓成本 App 能直接导入的 `timetable.json`。

---

> 👉 **第一次用请先看 [TUTORIAL.md](TUTORIAL.md)**
> —— 分步图文式教程，含「如何在 DevTools 里找到那条请求」和自检清单。

## ⚠️ 先读这一段

这个工具**没有在真实教务系统上验证过**。

它不硬编码接口细节（参数名、semester 编码、TOKEN 格式都不猜），
而是**以你从浏览器里复制的一条真实可用请求为准**——只要那条请求能返回课程数据，
脚本就能把 1~20 周都抓下来。

**所以第一步「找到那条请求」是整个流程的关键**，下面讲得很细。

---

## 已验证的接口事实（2026-10-19 实测）

以下结论来自**探测校方公开接口 + 分析门户前端代码**，不是猜测：

| 事实 | 证据 |
|---|---|
| 接口 baseURL | 前端配置 `udsBaseUrl = "https://portal.gdust.edu.cn/smart-admin-api/"` |
| 课程接口 | `GET /app/zf/get_student_course` —— 无凭证访问返回 `{"code":116,"msg":"认证失败","success":false}`（路径存在，只缺认证） |
| 认证方式 | 请求头 **`TOKEN`**，值取自登录响应的 `data.userBase.token` |
| 响应结构 | `data.courseList` 是课程数组 |
| 课程字段 | `courseName` / `teacherName` / `classroomName` / `dayWeek` / `whichSection` |
| 周次字段 | 每个条目自带 **`week`**（周次）与 **`singleOrDoubleWeek`**（单双周） |
| `whichSection` | 是**数字**（单节），不是 `"1-2"` 字符串 |
| 教务系统 | 正方（`http://172.16.254.1/xtgl/login_slogin.html`） |
| 网络 | 校外需校园网 / VPN；内网地址 `172.16.254.1` 从校外不通 |

### 这带来一个重要设计

因为每个条目**自带 `week`**，说明接口很可能**一次返回整学期**，由前端过滤。
所以本工具采用**两阶段聚合**：

1. 抓取时只负责收集条目（记下"这批来自第几周"作为兜底）
2. 抓完后按**条目自带的周次**归组，无周次字段才用兜底周次

这样接口无论「一次返回整学期」还是「按周返回」都能算对，且跨批次重复会被去重。
抓到第一批发现条目自带 `week` 时，会**提前结束逐周抓取**，不浪费请求。

## 第一步：找到那条课表请求（两种方式都要做）

1. **浏览器打开教务系统并登录**，进到「课表 / 我的课表」页面
2. 按 **F12** 打开开发者工具，切到 **Network（网络）** 标签
3. 点一下上方的 **Fetch/XHR** 过滤器（只看接口请求）
4. 在页面上**切换一次周次**（上周/下周），或者按 F5 刷新
5. 请求列表里会出现新请求。**逐个点开，看右侧的 Response（响应）**
6. 找到**响应里能看到课程名**（如「高等数学」「大学英语」）的那一个
7. 右键那条请求 →
   - **Copy → Copy link address** 得到完整 URL
   - **Copy → Copy as cURL**，从里面找出 `Cookie:` 那一行（Python 版需要）

> 💡 那个 URL 里通常带 `week=5` 或 `zc=5` 之类的周次参数。
> 如果 URL 里没有周次参数，说明你选的请求不对，换一个。

## 方式 A：浏览器控制台（推荐）

1. 保持在教务系统页面，F12 切到 **Console（控制台）** 标签
2. 打开本目录下的 `console_snippet.js`，**全选复制**
3. 粘贴到 Console 里，按 **回车**
4. 弹窗提示粘贴 URL → 粘贴第 1 步复制的地址
5. 弹窗提示抓取范围 → 直接回车（默认 `1-20`）
6. 控制台会逐周打印 `[✓] 第 1 周：12 条`，最后**自动下载 `timetable.json`**

> ⚠️ 如果控制台顶部提示「请勿粘贴代码」，先手动输入 `allow pasting` 再粘贴。
> 这是浏览器的防诈骗提示，不是我们的问题。

**成功标志**：控制台最后打印 `✅ 已下载 timetable.json` 并出现一张表。

## 方式 B：Python

不需要装任何第三方库（只用标准库）。

```powershell
cd E:\dev\projects\timetable\tools\gdust_crawl

python crawl.py `
  --url "https://教务系统域名/xxx/get_student_course?jobNumber=xx&year=2026&semester=1&week=5" `
  --cookie "JSESSIONID=xxx; CASTGC=yyy; ..." `
  --out 课表.json
```

参数：

| 参数 | 说明 |
|---|---|
| `--url` | 第 1 步复制的完整 URL（必填） |
| `--cookie` | 该请求的 Cookie 请求头内容（必填，整行粘贴也行，会自动去掉 `Cookie:` 前缀） |
| `--weeks` | 抓取范围，默认 `1-20`。支持 `1-8,10-16` |
| `--week-param` | 周次参数名，默认自动探测（`week`/`zc`/`weekNum`/`currentWeek`） |
| `--out` | 输出文件名，默认 `timetable.json` |
| `--delay` | 每周间隔秒数，默认 `0.6`（**不要调太低，别给学校服务器添乱**） |
| `--dump` | 把每周原始响应存到 `raw/` 目录，排查用 |

**Cookie 过期**会打印 `HTTP 401/403`，重新登录教务系统再复制一次即可。

**排查**：加 `--dump` 重跑，看 `raw/week01.json` 里的原始响应到底长什么样。

## 输出格式

```json
{
  "1": [
    {
      "courseName": "高等数学BⅠ",
      "teacher": "谌凤霞",
      "classroomName": "松6-502",
      "dayWeek": 2,
      "whichSection": "7-8"
    }
  ],
  "2": [ ... ],
  "...": []
}
```

字段说明：

| 字段 | 含义 | 说明 |
|---|---|---|
| 周次 | **字典的键**（字符串 `"1"`..`"20"`） | 一门跨多周的课会在每个周键里都出现 |
| `courseName` | 课程名 | |
| `teacher` | 教师 | |
| `classroomName` | 地点 | |
| `dayWeek` | 星期 1~7 | |
| `whichSection` | 节次，如 `"7-8"` | 单节写成 `"7-7"` |

App 导入时会自动做两级聚合：
1. 同周内相邻节次合并（`"7"` + `"8"` → 7~8 节）
2. 跨周相同记录合并成一门课并计算周次

## 第二步：导入到 App

1. 把 `timetable.json` 传到手机（微信文件传输 / 数据线 / 网盘都行）
2. App → **设置** → **导入课表** → **从文件导入（.json）**
3. 选那个文件 → 预览 → 确认
4. ⚠️ **手动设置「第一周周一」**——这个 JSON 格式不含学期元信息

> 为什么不含？App 的 JSON 导入契约就是「周次 → 课程列表」的纯映射。
> 带上 `meta` 字段反而会被判定成「App 自己的导出格式」而拒绝。

## 常见问题

### 「所有周都没有抓到课程」

按顺序排查：

| 可能性 | 怎么确认 |
|---|---|
| Cookie 过期 | Python 会打印 HTTP 401/403；控制台版看 Network 里那条请求的状态码 |
| 选错请求 | 你复制的 URL 在浏览器里直接打开，应该能看到 JSON 且含课程名 |
| 需要校园网/VPN | 校外访问学校内网地址会连不上 |
| 接口要用 POST | 本脚本只发 GET。如果那条请求是 POST，看下面的「进阶」 |

**加 `--dump`（Python）或看 Console 输出**，能看到原始响应，绝大多数问题一眼就明白。

### 「抓到了，但每周内容都一模一样」

说明周次参数被接口忽略了（它一次返回整学期）。

- Python 版会自动检测并警告
- 解决办法：换一个真正按周返回的请求；或在浏览器里手动切周，观察 URL 变化

### 「课程数量对，但节次是空的」

接口里没有节次字段，或者字段名不在别名表里。

- 用 `--dump` 看原始响应，找到节次字段名
- 告诉我，我加进别名表

### 「课名/教师/地点位置错乱」

同上——字段名不匹配。看原始响应告诉我实际字段名。

## 进阶：如果那条请求是 POST

本脚本只支持 GET（95% 的课表接口是 GET）。

如果是 POST：

1. 在 DevTools 里右键那条请求 → **Copy → Copy as cURL (bash)**
2. 把 cURL 命令存成 `request.sh`，把里面的 `week` 值改成 `7`
3. 用一个 `for` 循环跑 1~20，把每个响应存成 `week01.json` … `week20.json`
4. 把这些文件喂给脚本：

```powershell
python crawl.py --from-files .\raw --out 课表.json
```

> ⚠️ `--from-files` 这个参数**目前还没实现**。需要的话告诉我，我加上。

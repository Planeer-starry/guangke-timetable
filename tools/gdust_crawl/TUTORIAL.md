# 爬虫使用教程

把教务系统的课表抓成 App 能直接导入的 `timetable.json`。

> ⚠️ 读之前先知道一件事：
> 这个工具**没有在你的真实账号上验证过**。它的接口信息来自实测探测和
> 门户前端代码分析（见 README「已验证的接口事实」），逻辑有 62 项自动化断言覆盖，
> 但**真正跑通需要你自己走一遍**。下面每一步都写了「成功应该看到什么」，
> 对不上就查最后的排查表。

---

# 三种用法，按「傻瓜程度」选

| 方式 | 需要什么 | 要不要「找请求」 | 适合谁 |
|---|---|---|---|
| **① 图形界面** | 电脑装 Python，双击 `启动.bat` | ❌ **不用** | **只想快点拿到课表（推荐）** |
| ② 浏览器控制台 | 什么都不用装 | ✅ 要 | 不想装 Python |
| ③ 命令行 | Python + 手动复制 Cookie | ✅ 要 | 想脚本化 / 批量跑 |

> 三种方式的**输出完全一样**（都是 `timetable.json`），导入 App 的步骤也相同。

---

# 方式 ①：图形界面（最省事）

## 为什么它不用「找请求」

因为接口细节已经实测确认（见 README「已验证的接口事实」），
工具可以自己拼出正确的地址，你只需要提供两样东西：

```
学号     ← 你自己知道
TOKEN    ← 浏览器里一行命令就能复制
```

学年、学期、总周数、当前周，工具会先调 `get_school_calendar` **自动查出来**，
连「抓几周」都不用你填。

## 操作

### 1. 打开工具

双击 `tools/gdust_crawl/启动.bat`

> ⚠️ 需要电脑装了 Python 3.10+。没装的话，用「方式 ②」，那个什么都不用装。

### 2. 点「打开教务系统门户」，登录

工具窗口的 ① 区域有按钮。用学号密码登录，进到「我的课表」页面。

### 3. 复制 TOKEN（一行命令）

工具窗口的 ② 区域：

1. 点 **「复制一行命令」** —— 命令 `copy(sessionStorage.getItem("TOKEN"))` 进剪贴板
2. 切到浏览器，**F12 → Console（控制台）**
3. 粘贴，**回车**

> 浏览器若提示「请勿粘贴代码」，先手动输入 `allow pasting` 回车。

✅ **成功标志**：Console 显示 `undefined` —— 这是正常的（`copy()` 没有返回值），
TOKEN 已经进剪贴板了。

### 4. 回工具，填学号 + 读 TOKEN

1. **学号**：填你的学号
2. 点 **「从剪贴板读取 TOKEN」**
3. （可选）勾「显示」确认 TOKEN 读进来了（一长串字母数字）

### 5. 点「开始抓取」

工具会自动：

```
① 查询学期信息（学年 / 学期 / 总周数）
② 逐周抓取课程
③ 整理数据
④ 弹出保存对话框
```

**日志区会实时显示进度**，例如：

```
① 查询学期信息（学年 / 学期 / 总周数）…
  学年 2026-2027 · 学期 1 · 总周数 20
② 开始抓取 1..20 周…
  ✓ 第 1 周：37 条（37 条自带周次）
    ↳ 条目自带周次 → 接口一次返回整学期，提前结束

✓ 完成：20 周，共 142 条
  周次范围 1 ~ 20

下一步：点「保存为 timetable.json」，再传到手机导入。
```

✅ **成功标志**：弹出保存对话框 → 选个位置保存。

### 6. 导入 App

见下面「第 ③ 步：导入 App」。

## 出错了看日志

日志区的提示是给人看的，例如：

| 日志 | 意思 | 怎么办 |
|---|---|---|
| `TOKEN 无效或已过期` | 登录态过期了 | 回第 3 步重新复制 TOKEN |
| `网络不通。校外访问需要校园网或学校 VPN` | 没连校内网 | 连校园网或 VPN |
| `没抓到任何课程` | 学期选错 / 该学期没课 | 确认教务系统里能看到课表 |

```
① 浏览器登录教务 → 找到课表请求        （2 分钟，最关键）
        ↓

        ↓
④ 手动设置「第一周周一」                （10 秒）
```

**总耗时约 4 分钟。** 第 ① 步占了 2 分钟，也是最容易卡住的地方，下面讲得最细。

# 第 ① 步：找到「那条请求」

## 为什么必须自己找？

教务系统的接口地址、参数名、认证方式都**可能变**。与其让脚本猜（猜错就是白跑），
不如让你从浏览器里复制**一条已经能返回数据的请求**——它是事实，不会错。

## 操作（以 Chrome / Edge 为例）

### 1. 登录并进课表页

浏览器打开教务系统，登录，进到**「课表查询 / 我的课表」**页面。

> 💡 校外要连校园网或学校 VPN，否则后面请求会失败。

### 2. 打开开发者工具

按 **F12**（或 `Ctrl+Shift+I`），切到 **Network（网络）** 标签。

### 3. 只看接口请求

点一下筛选栏里的 **`Fetch/XHR`**（在 All / Fetch/XHR / JS / CSS … 那一排）。

这样列表里只剩接口请求，噪音少很多。

### 4. 触发一次课表请求

**切一次周次**（点「上一周 / 下一周」），或者按 **F5** 刷新页面。

Network 列表里会冒出新的请求。

### 5. 人肉找出「课程数据」那个请求

逐个点开列表里的请求，看右侧的 **Response（响应）** 标签页。

**找的是响应里能看到课程名的那一个**，例如：

```json
{
  "code": 0,
  "data": {
    "courseList": [
      {
        "courseName": "高等数学BⅠ",
        "teacherName": "谌凤霞",
        "classroomName": "松5-307",
        "dayWeek": 3,
        "whichSection": 5,
        "week": "1-16",
        "singleOrDoubleWeek": null
      }
    ]
  }
}
```

**认准这几个特征**（任一即可）：
- 响应里出现 `courseList`
- 或者出现 `courseName` / `teacherName`
- 或者直接能看到中文课程名

> 💡 通常名字里带 `get_student_course` 或 `course`、`kebiao`、`schedule`。
> 广科是 `get_student_course`。

### 6. 复制 URL

**右键那条请求 → Copy → Copy link address**

✅ **成功标志**：复制的 URL 里能看到 `week=数字`（或 `zc=`），例如：

```
https://portal.gdust.edu.cn/smart-admin-api/app/zf/get_student_course?jobNumber=2026xxxx&year=2026&semester=1&week=8
```

> ⚠️ **URL 里没有周次参数 = 选错请求了**，回到第 5 步重找。
> 脚本靠替换这个参数来逐周抓取。

# 第 ② 步：跑脚本

## 方式 A：浏览器控制台（推荐，不用装任何东西）

### 1. 准备脚本内容

打开 `tools/gdust_crawl/console_snippet.js`，**全选复制**。

> 也可以在 GitHub 上打开这个文件，点右上角 Raw，再 Ctrl+A 全选复制。

### 2. 切到 Console

还在 F12 里，切到 **Console（控制台）** 标签。

### 3. 粘贴并回车

粘贴刚才复制的内容，按 **回车**。

> ⚠️ 如果控制台顶部红字提示「请勿粘贴代码 / Don't paste code」，先手动输入
> `allow pasting` 回车，再粘贴。这是浏览器防诈骗提示，不是脚本的问题。

### 4. 按提示输入

**弹窗 1**：粘贴第 ① 步复制的 URL → 确定

**弹窗 2**：抓取范围，直接回车（默认 `1-20`）

### 5. 看控制台输出

正常会逐行打印：

```
[*] 周次参数: week
[*] 抓取 1..20，共 20 周
[✓] 第 1 周：37 条
    ↳ 条目自带 week 字段 → 判定为「一次返回整学期」，不再逐周抓取
────────────────────────────────────────────────
✅ 已下载 timetable.json
   周数 20（1..20），条目 142
```

✅ **成功标志**：浏览器**自动下载**了 `timetable.json`，控制台底部打印
`✅ 已下载 timetable.json` 并出现一张每周条数的表。

> 💡 看到 `↳ 条目自带 week 字段` 是**好事**——说明接口一次返回整学期，
> 脚本只抓一次就停了，省了 19 次请求。

## 方式 B：Python（适合脚本化）

```powershell
cd E:\dev\projects\timetable\tools\gdust_crawl

python crawl.py `
  --url "第①步复制的URL" `
  --cookie "复制的Cookie" `
  --out 课表.json
```

**Cookie 怎么拿**：Network 里右键那条请求 → **Copy → Copy as cURL**，
从粘贴出来的文本里找 `Cookie:` 那一行，把它后面的内容整段复制即可
（`Cookie: ` 前缀带着也行，脚本会自动去掉）。

✅ **成功标志**：

```
[*] 周次参数: week（当前值 8）
[*] 抓取范围: 1..20（共 20 周）
[✓] 第 1 周：37 条（37 条自带周次）
    ↳ 条目自带 week 字段 → 判定为「一次返回整学期」，不再逐周抓取

[✓] 已写出 课表.json
    周数 20，条目 142
```

# 第 ③ 步：导入 App

1. 把 `timetable.json` 传到手机（微信文件传输助手 / QQ / 数据线都行）
2. App → **设置** → **导入课表** → **从文件导入（.json）**
3. 选那个文件
4. 预览页会显示识别到的课程数 → 点 **确认导入**

✅ **成功标志**：预览页显示「识别出 N 门课」，导入后周视图能看到课程。

# 第 ④ 步：设置第一周周一

JSON 格式**不含学期元信息**（App 的 JSON 导入契约就是「周次 → 课程列表」的纯映射），
所以导入后要点：

**App → 设置 → 学期 → 选择第一周周一**

✅ **成功标志**：周视图标题显示正确的学期名和周次，今天那列高亮。

> 💡 想知道第一周周一是哪天？看教务课表页顶部的「第1周」日期，
> 或问同学。

# 排查表

## 「所有周都没有抓到课程」

| 可能性 | 怎么确认 | 解决 |
|---|---|---|
| **选错请求** | 把 URL 直接在浏览器地址栏打开，看有没有 `courseList` | 回第 ① 步第 5 节重找 |
| **登录态过期** | 控制台有 `[✗] HTTP 401/403` | 重新登录教务系统，重新复制 URL |
| **需要校园网/VPN** | `[✗] 网络错误` | 连校园网或学校 VPN |
| **URL 没周次参数** | 脚本提示「找不到周次参数」 | 换一个真正的课表请求 |

## 「能抓到，但课程不对」

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 课名/地点是空的 | 字段名不在别名表里 | 把原始响应贴出来（脱敏后），我加别名 |
| 节次全是空 | 字段名不同 | 同上 |
| 周次全错 | `week` 字段格式特殊 | 加 `--dump` 看原始响应 |
| 一节课出现很多次 | `week` 解析出了多周但接口其实是单周 | 把 `--weeks` 缩到 `1-2` 试一次，看条目数 |

## 「Python 报 Cookie 相关错误」

- Cookie 复制不完整 → 重新 Copy as cURL，确保整行都复制了
- Cookie 已过期 → 重新登录后再复制

# 附：脚本做了什么

知道原理有助于排查：

```
1. 从你的 URL 里找出周次参数名（week / zc / ...）
2. 循环替换该参数（1..20），逐个请求
3. 每个响应递归遍历，找出「同时有课程名和星期」的对象
4. 每个条目：读它自带的 week（周次）+ singleOrDoubleWeek（单双周）
5. 两阶段聚合：
   · 有 week 字段 → 按它归组（并过滤单双周）
   · 没有        → 归到抓取它的那一周
   · 全量去重 + 按星期/节次排序
6. 输出 {"1": [...], "2": [...], ...} 的 JSON
```

**关键设计**：如果第一批条目就自带 `week` 字段，说明接口一次返回整学期，
脚本会**立刻停止逐周抓取**——所以你看到「只抓了 1 周就结束」是正常的，不是bug。
